Built in the open

Questions

Before you download

Which coding agents does Zurafa work with?

Any agent that runs in a terminal. Claude Code, Codex, and Gemini get their own pane icons, and any program can report its status with zurafa report.

Is Zurafa free?

Yes. Zurafa is free, and its source is public on GitHub.

Does it run on Intel Macs?

Not yet. The current build needs an Apple Silicon Mac running macOS 14 or newer.

How does Zurafa know an agent is blocked?

The agent tells it. A program reports working, done, blocked, or error over OSC 7501, usually with one zurafa report line in a hook. Zurafa never guesses by reading terminal text. Read the status guide.

Can I keep my Ghostty theme?

Yes. Zurafa imports Ghostty themes, colors, and fonts. See appearance settings.

What happens to my panes when the app restarts?

The Rust daemon keeps your processes running and the app restores pane content after a restart or update. Sessions do not yet survive a restart of the daemon itself.

How do updates work?

Zurafa checks for new releases through Sparkle and installs them from inside the app.

Can I work on remote machines?

Yes. Open tabs on saved SSH hosts and local VMs, or connect directly to machines on your tailnet. See remote access.
