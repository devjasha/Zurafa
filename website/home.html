Questions

Before you download

Which coding agents does Zurafa work with?

Any agent that runs in a terminal. Claude Code, Codex, and Gemini get their own icons. Run zurafa setup claude once and connect the rest.

Is Zurafa free?

Yes. Zurafa is free, and its source is public on GitHub.

Does it run on Intel Macs?

Not yet. It needs an Apple Silicon Mac running macOS 14 or newer.

How does Zurafa know an agent is blocked?

The agent tells it with one zurafa report line in a hook. Zurafa never guesses from terminal text. Read the status guide.

What happens to my panes when the app restarts?

The daemon keeps your processes running and the app restores pane content after a restart or update.

Is there an iPhone app?

Yes, in early beta. It connects over Tailscale and you build it from source in Xcode for now.
